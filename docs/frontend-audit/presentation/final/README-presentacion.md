# Dinamic Clean — Propuesta UX/UI

## Qué archivo usar para presentar
**`Dinamic-Clean-Propuesta-UXUI.pptx`** (25 slides). Abrirlo con PowerPoint. Los 5 videos están dentro del archivo: se reproducen al hacer clic sobre la imagen en el modo presentación. No necesita la carpeta `videos/` para funcionar.

Si se abre en otro programa (Keynote, Google Slides, visor de vista previa) y un video no se reproduce, usar los archivos de la carpeta `videos/`.

## Qué archivo compartir
**`Dinamic-Clean-Propuesta-UXUI.pdf`**. Se entiende completo sin videos: cada slide de video muestra una imagen real del clip y, a la derecha, lo que se vio.

Para que el botón ▶ del PDF abra el video, el PDF y la carpeta `videos/` deben estar juntos y el PDF abrirse con Adobe Acrobat. Si no, las slides igual se leen sin el video.
